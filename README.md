# Sistema-de-Visao-Computacional-para-Deteccao-e-Analise-de-Objetos-em-Tempo-Real
Desenvolver uma aplicação em Python que utilize técnicas de computação visual para identificar, classificar ou rastrear objetos em imagens, vídeos ou webcam. O projeto deve utilizar obrigatoriamente a biblioteca OpenCV e, opcionalmente, modelos de detecção baseados em YOLO (You Only Look Once).
